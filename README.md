## Аналіз виконання вимог
Створено Windows Forms застосунок (C++/CLI) для аналізу споживання води за 7 днів. Реалізовано графічний інтерфейс із полями вводу, захист від некоректних даних (TryParse), використання звичайних вказівників (ptr, pTotal), усі розрахунки через їхню арифметику (*(ptr + i)) та можливість повторного аналізу без перезапуску.
## Висновок
Закріплено навички роботи з Windows Forms та вказівниками C++. Програма повністю виконує вимоги Варіанта 15: обчислює загальне та середнє споживання, знаходить день із найбільшими витратами, кількість днів нижче середнього та різницю між першим і останнім днем.
